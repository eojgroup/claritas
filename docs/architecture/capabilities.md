# Claritas Business Capabilities

| Code | Capability Name             | Description                                                                 | Example Outcomes                                  |
|------|-----------------------------|-----------------------------------------------------------------------------|--------------------------------------------------|
| C01  | Data Aggregation            | Collect data from reviewed, commercially reusable global and official sources | Unified GDELT, official RSS, weather, market, leadership and transport data |
| C02  | Data Enrichment             | Enhance raw data with metadata, context, and semantic meaning               | Tagged, categorized, and cleaned data            |
| C03  | Insight Generation          | Use analytics and ML to produce actionable insights                         | Risk flags, predictive indicators, trend alerts  |
| C04  | Real-Time Notifications     | Materialize watchlist eligibility and deliver bounded in-app/APNs alerts without conflating provider acceptance with user acknowledgement | Exact-event push handoff, invalid-token handling, acknowledgeable alerts |
| C05  | Interactive Visualization   | Present data visually for comparison and exploration                        | Charts, maps, dashboards                         |
| C06  | Custom Reporting            | Allow users to generate and export tailored reports                         | PDF/Excel reports based on filters               |
| C07  | External Integration        | Provide APIs for external apps and partners to access Claritas data         | Developer APIs, Webhooks                         |
| C08  | Mobile Accessibility        | Deliver core functionality on mobile devices                                | Native apps with offline support                 |
| C09  | User Preferences & Profiles | Support saved queries, alert configs, and personal dashboards               | Personalized views and notifications             |
| C10  | Governance & Access Control | Ensure secure, role-based access to features and datasets                   | Role-based permissions, audit trails             |
| C11  | Transport Intelligence      | Normalize live aviation and maritime movement into country-linked routes and qualified trends | Flight numbers, shipping corridors, port departures, country profiles, briefing takeaways |
| C12  | Source Governance           | Enforce provenance, reuse rights, attribution, country scope and retirement decisions | Auditable active-source register and documented exclusions |
| C13  | Cost Governance             | Bound compute, storage, polling, history and connection growth | Cost baseline, retention limits, demand batching and explicit scale-up triggers |
| C14  | Cross-domain Event Intelligence | Correlate independently sourced evidence through event family/time and a required spatial, specific-location or entity anchor without asserting causation | Unified Signal Desk, auditable correlation decisions, navigable evidence graph, watchlists and alert candidates |
| C15  | Earth Observation Context | Use exact-AOI events to discover, rank, render and govern physical observations; keep browse imagery and model interpretation epistemically distinct | Sentinel scenes/private previews, FIRMS observations, GIBS WMTS context, free-only bounded vision interpretation and qualified comparisons |
| C16  | Spatial Asset Graph | Normalize countries, ports, airports, chokepoints and production regions with provenance | PostGIS proximity matching, monitored tiers and cross-domain location linkage |
